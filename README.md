# 수령길-컴맹 v0.9.3 — Mobile Rebuild

모바일 화면을 다시 한 번 완전히 분리한 안정화 버전.

- 모바일에서 로컬 저장 상태·데스크톱 메뉴 숨김
- 메모 목록 검색 영역 2행 고정
- 상세 화면은 검색 영역을 완전히 숨김
- 생각 연결 컨트롤 2열 고정, 그래프는 남는 높이 전체 사용
- 편집창 전체화면화 및 툴바 가로 스크롤
- PWA/Service Worker는 모바일 안정화 완료 전까지 제거

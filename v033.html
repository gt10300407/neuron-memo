주제자동 연결직접 연결
자동 연결은 공통 단어 기준. 그래프 확대·이동은 이 화면 안에서만 동작해. 직접 연결은 [직접 연결] 후 메모 2개를 차례로 클릭해.

GitHub 동기화 설정
메모 데이터는 전용 비공개 GitHub 저장소의 data/state.json에 저장해. 토큰은 GitHub에 올리지 않고 이 기기 브라우저에만 저장돼.
아직 연결하지 않았어.
GitHub 비밀번호를 넣지 마. 전용 저장소 하나에만 Contents: Read and write 권한을 준 Fine-grained PAT만 사용해.
